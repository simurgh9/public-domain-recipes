_sugo_ is a clone of the Hugo theme [_lugo_](https://github.com/lukesmithxyz/lugo) by Luke Smith, which is non-free.
It is distributed under the [Unlicense](https://publicdomainrecipes.com) to align with the [Public Domain Recipes](https://publicdomainrecipes.com), which it is intended to serve.
By submitting anything to this theme, you release your contribution under the Unlicense.

Some parts were taken from [Public Domain Recipes](https://https://publicdomainrecipes.com), the rest was written from scratch to produce an output similar to that of lugo, without looking at the source code of lugo itself.

_sugo_ is an Italian word that means roughly _sauce_.
